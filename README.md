# 🎮 BGMI Gaming Website

A modern and attractive BGMI-inspired gaming website built using HTML and CSS. It features a dark gaming theme, soldier character section, glowing effects, and a responsive layout.

## 🚀 Features

- 🎯 Attractive gaming-themed UI
- 🪖 BGMI-inspired character showcase
- 🟠 Gaming-style logo and navigation bar
- ✨ Neon glow and floating animations
- 📱 Responsive design for mobile and desktop
- ⚡ Smooth scrolling and hover effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts

## 📂 Project Structure

```text
bgmi-website/
├── index.html
├── style.css
├── README.md
└── images/
    ├── bgmi-character.png
    └── bgmi-logo.png
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure the character image is inside the `images` folder.
4. Open `index.html` in your browser.
5. Alternatively, use the Live Server extension in VS Code.
